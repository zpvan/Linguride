# Level Badge UI 重构与文案优化

> 将 CEFR 等级选择器从独立 Card 重构为 Header 内的紧凑徽章，点击展开下拉选择，并添加中国考试体系对标说明。

## 解决什么问题

传统的等级选择器占据独立的 Card Section，消耗宝贵的 Popup 空间，且切换等级需要滚动查找。重构后的 Level Badge 将等级选择嵌入 Header，一眼可见当前水平，点击即可快速切换，同时通过中国考试对标（如"A2 中考水平"）帮助用户直观理解各等级含义。

## 工作原理

```
用户点击 Level Badge → 下拉菜单展开 → 选择等级 → 自动保存 → 关闭下拉
                                              ↓
                                   点击外部区域 → 关闭下拉
```

1. **Badge 展示**：Header 右侧显示 `Lv.A2` 格式的徽章，游戏风简洁直观
2. **下拉交互**：点击 Badge 展开 6 个等级选项（A1-C2），每项显示等级代码 + 中国考试对标
3. **自动保存**：选择后立即通过 Chrome Storage API 持久化，无需确认按钮
4. **联动刷新**：若释义/混杂模式已开启，自动重新触发以应用新等级

## 主要模块

| 文件 | 职责 |
|------|------|
| `popup.html` | 定义 Header 内的 `level-badge-wrapper` 结构和 6 个等级选项 |

## CEFR 等级与中国考试对标

| 等级 | 对标说明 | 典型用户 |
|------|----------|----------|
| A1 | 初中入门 | 刚接触英语的初中生 |
| A2 | 中考水平 | 中考备考或刚通过中考 |
| B1 | 高考水平 | 高考备考或普通大学新生 |
| B2 | 四六级 | 通过 CET-4/CET-6 |
| C1 | 考研/专八 | 研究生入学或英语专业高年级 |
| C2 | 专业翻译 | 翻译从业者或接近母语水平 |

## 技术亮点

1. **游戏风徽章设计**：`Lv.A2` 格式借鉴游戏等级显示，简洁有辨识度，比 "Level: A2" 更紧凑
2. **零配置自动保存**：选择即保存，利用 Chrome Storage API 无感持久化，避免"忘记点保存"问题
3. **外部点击关闭**：通过 `document.addEventListener('click')` 监听，点击下拉以外区域自动关闭
4. **模式联动刷新**：更改等级后，若释义/混杂模式已开启，自动先关后开，确保内容应用新等级
5. **CSS 动画过渡**：下拉菜单使用 `opacity + transform + visibility` 组合实现平滑展开/收起效果
