# 影子跟读法（Shadow Reading）

> AI 驱动的英语口语跟读训练，从准确度、流利度、语调、节奏四个维度全方位评估用户发音。

## 解决什么问题

传统发音练习只能告诉用户"对不对"，却无法指出"哪里不对"以及"如何改进"。影子跟读法通过 AI 智能分句 + 四维度评估 + 问题词示范，帮助用户系统性提升口语能力。

## 工作原理

```
用户输入英文文本
       ↓
   AI 智能分句
       ↓
  显示练习面板
       ↓
┌──────────────────────────────────────┐
│  ① 范读 → ② 跟读录音 → ③ AI 评估   │
│              ↓                        │
│     显示四维度评分 + 问题词高亮       │
│              ↓                        │
│     ④ 重试 / 下一句 → 循环           │
└──────────────────────────────────────┘
       ↓
   练习完成统计
```

## 主要模块

| 模块 | 职责 |
|------|------|
| `shadowReading.ts` | 类型定义：模式、配置、句子状态、评估结果等 |
| `shadowPrompts.ts` | AI Prompt 配置：分句规则、评估标准、输出格式 |
| `shadow.ts` | 核心逻辑：状态管理、流程控制、范读/录音/评估协调 |
| `tutor.ts` | UI 集成：模式切换、事件绑定、结果渲染、快捷键 |
| `service-worker.ts` | 后台服务：处理 `SPLIT_SENTENCES` 和 `SHADOW_ASSESS` 消息 |

## 技术亮点

### 1. 依赖注入解耦语音识别

`shadow.ts` 不直接创建 `WebSpeechRecognizer`，而是通过 `injectRecognizer()` 接收外部注入。这样设计的好处：
- 业务逻辑与具体实现解耦
- 便于测试时 mock 语音识别
- 未来可替换为其他识别引擎

```typescript
// tutor.ts 负责创建和注入
const shadowRecognizer = new WebSpeechRecognizer();
shadow.injectRecognizer(shadowRecognizer);
```

### 2. 三种跟读模式适配不同水平

| 模式 | 英文名 | 描述 | 适合 |
|------|--------|------|------|
| 逐句 | sentence | 先听完范读，再跟读 | 初学者 |
| 影子 | shadow | 范读后延迟 0.5s 开始跟读 | 中级 |
| 同步 | sync | 与范读同时开始 | 高级 |

### 3. 四维度评估体系

扩展现有发音评估，新增语调和节奏两个维度：

| 维度 | 权重 | 评估内容 |
|------|------|----------|
| 准确度 | 30% | 单词是否正确发音和识别 |
| 流利度 | 25% | 是否有停顿、重复、卡顿 |
| 语调 | 25% | 升降调是否自然 |
| 节奏 | 20% | 停顿位置、重音、语速 |

### 4. 问题词高亮 + 示范发音

AI 识别出发音问题后，会返回问题词列表。用户点击问题词可听到慢速示范（0.8x 语速，朗读两遍）。

### 5. 快捷键支持

| 快捷键 | 功能 |
|--------|------|
| `Space` | 开始/停止录音 |
| `Enter` | 播放范读 |
| `Tab` | 跳过当前句 |
| `R` | 重新练习（评估结果页） |

### 6. 配置持久化

用户的模式和语速偏好保存在 `localStorage`，下次打开自动恢复：
- `lingride_shadow_mode`: 跟读模式
- `lingride_shadow_speed`: 语速
- `lingride_headphone_hint_dismissed`: 耳机提示是否已关闭
